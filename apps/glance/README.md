# Glance Dashboard

## ConfigMap Architecture

Glance uses two ConfigMaps with different management strategies:

### `glance` — managed by kustomize/ArgoCD

Tracked in git and generated by `kustomization.yaml`. Contains the main dashboard config and page layouts:

- `config/glance.yml`
- `config/home.yml`
- `config/media.yml`
- `config/homelab.yml`

### `glance-feeds` — managed locally by launchd + Ansible

**Not tracked in git.** The feed files (`config/bookmarks.yml`, `config/feeds/*.yml`) are gitignored and managed by a local automation pipeline:

1. A launchd service (`com.homelab.glance-feeds.plist`) watches for changes to the local feed files
2. When changes are detected, it runs `ansible/scripts/deploy-glance-feeds.sh`
3. That script runs the Ansible playbook which applies the ConfigMap directly to the cluster

**Do NOT add the feed files to `kustomization.yaml`** — they are intentionally gitignored and will cause ArgoCD's kustomize build to fail with "no such file or directory".

### Manual feed deployment

```bash
ansible-playbook ansible/playbooks/glance-feeds.yml
```
