# homelab

A homelab is a home computing lab. Essentially it is a place for me to mess around with a larger computing system without fear of messing anyone else up. My homelab has evolved over time (with previous versions not being tracked with git) and concluding with the Kubernetes based homelab in this repository. I've been able to host my own web apps, websites, APIs, and run AI locally using Ollama.

> My homelab is now tracked using self hosted Gitea. This repo will no longer be updated.
